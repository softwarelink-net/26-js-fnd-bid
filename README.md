## 部署与运行说明

### 环境要求
- Node.js >= 18.0.0
- npm >= 9.0.0 或 pnpm >= 8.0.0

### 安装依赖
```bash
npm install
```

### 本地运行
```bash
# 启动前端本地开发服务器 (纯前端运行，自动加载本地 SQLite 数据库文件)
npm run dev
```
启动完成后，在浏览器打开终端输出的本地开发服务器地址（如 `http://localhost:5173/`）即可体验完整系统。

## 招标公告全文

### 1. 标题
资金中心信息系统外包服务采购竞争性磋商公告

### 2. 项目发包方
江苏省省级机关住房资金管理中心

### 3. 项目编号
JSZC-320000-NJJD-C2026-0016

### 4. 项目发布时间
2026-09-15 15:00:00

### 5. 关键词
江苏省省级机关住房资金管理中心, 资金中心信息系统, 外包服务采购, 银企直联对账, 公积金风控, JSZC-320000-NJJD-C2026-0016, 江苏政府采购

### 6. 摘要
江苏省省级机关住房资金管理中心委托南京金鼎工程造价评估有限责任公司，对资金中心信息系统外包服务采购项目组织竞争性磋商，预算金额与最高限价为1,216,000.00元。采购内容为资金中心信息系统外包服务1年，不接受联合体投标，投标文件提交截止时间为2026年09月29日14:30。

### 7. 技术要点
- **省级机关公积金与住房补贴资金账户精准管理**：覆盖全省数千家行政事业单位资金归集。
- **多承办银行银企直联专线高并发清算与日终自动对账平账**：保障资金流转零长短款差错。
- **公积金非理性提取与虚构材料智能反欺诈识别**：联动跨域大数据模型实施秒级阻断。
- **纯前端 WebAssembly sql.js 边缘极速响应体系**：零服务器常驻运维开销，数据本地极简持久化。

### 8. 技术创新性
- **全要素省级机关住房公积金运营与资产流动性安全全景大屏**：宏观洞察备付金保证率、个贷逾期率与外包运维保障指标。
- **统一业务命名空间严格隔离架构**：统一采用专用数据表前缀与独立本地存储载体，杜绝多系统交叉干扰。
